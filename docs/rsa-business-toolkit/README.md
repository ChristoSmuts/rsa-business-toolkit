## Three numbers that changed in 2026

Most websites still have these wrong.

| Number | What it is |
|---|---|
| R2.3 million | VAT registration becomes compulsory here, not R1 million |
| R120,000 | Voluntary VAT registration, up from R50,000 |
| R600,000 | Turnover tax is 0% up to this, under a R2.3 million ceiling |

If a website tells you the VAT threshold is R1 million, that site is out of date.

## Conventions used

- Paragraphs that stay close to the wording of a law are followed by a blockquote starting **In plain words**, which says the same thing in everyday English. If the legal sentence is hard, read that instead.
- Each heavy document opens with a "Words used in this file" table.
- Fenced code blocks are prompts meant to be copied into an AI chat tool.
- `- [ ]` lines are checklists.
