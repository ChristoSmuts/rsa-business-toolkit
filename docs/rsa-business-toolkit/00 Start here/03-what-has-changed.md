# Changelog and redline

Last updated: 13 September 2026

This records what has changed in the toolkit, and where the Google Drive copy and this markdown copy differ.

There are two copies of this toolkit:

- **This markdown set** (the zip). The source of truth. Plain text, nothing lost in conversion.
- **The Google Drive set.** 34 documents and 2 spreadsheets, fully interlinked.

The Drive connector can create documents but cannot edit an existing one. So when the markdown changes, the Drive copy needs a manual paste. This file tracks that gap.

## Change 1: shortcut path for people whose name is already decided

**Date:** 13 September 2026
**Reason:** The branding sequence assumed every reader was starting from nothing. Someone with a registered name was being sent through a naming prompt and a naming-focused competitor scan they did not need.

### Added

[Already have your name (shortcut)](../02%20Branding%20and%20marketing/00-already-have-your-name.md) — new file, about 1,200 words.

What it does:

- Maps all 12 branding prompts to skip / modify / still do. The answer is: **skip one, modify one, do the other nine.**
- Supplies a replacement for Prompt 2 that drops naming patterns and adds two questions the original never asked: what does my name already suggest visually, and does it create visual constraints (too long for a vehicle door, awkward at small sizes, hard to set in type).
- Records the three checks still worth doing when a company name is registered: domain and handles, CIPC trade mark search, and saying the name aloud to speakers of the relevant languages.
- Explains that a CIPC company name protects nothing in the market.
- Repeats the section 32 requirement, which now applies because the name is registered.

**Status in Drive:** DONE. Created as "00 Already have your name - start here in this folder" in the 02 Branding and marketing folder.

## Change 2: mood and materials step

**Date:** 13 September 2026
**Reason:** Nothing in the branding sequence established the overall visual direction. Prompts 5, 7 and 8 each made their own aesthetic call, so the logo, palette and photography could contradict each other. Materials were also absent everywhere except as constraints.

### Added

[Mood and materials (use after Prompt 4)](../02%20Branding%20and%20marketing/02-mood-and-materials.md) — new file, about 1,300 words. Prompt A sets a visual territory; Prompt B sets signage, print, vehicle and clothing materials. Includes a line to paste into Prompts 5, 7 and 8 that forces them to agree.

Two things were verified before writing it:

- **Colour psychology is weak.** Elliot and Maier (2014) find no universal colour meaning. The famous "62 to 90% of snap judgment is colour" figure traces to a 2006 literature review, not an experiment. What holds up is colour-to-personality fit (Labrecque and Milne, 2012). The prompts therefore ask about fit and difference, and instruct the AI not to give colour meanings.
- **South African UV is a real design constraint.** Zone 3 UV, vinyl fading in roughly a third of its European life, horizontal installs losing 50 to 70%. Cast versus calendered guidance added. Sources and their limitations recorded.

**Status in Drive:** DONE. Created as "01a Mood and materials - decide this before the logo".

## Change 3: missing entry document in the Core folder (fix)

**Date:** 14 September 2026
**Reason:** A numbering error, spotted by the user. In Drive the 01 Core folder ran 02 to 09 with no 01, because [Core: start here](../01%20Core%20-%20applies%20to%20everyone/01-core-start-here.md) had been folded into the root START HERE when Drive was built. The result looked like a missing file, and it left Core as the only folder without its own entry document. Every other folder has one.

### Added

Drive document "01 Start here - what is in this folder" in the 01 Core folder. It carries the reading order, a table of the eight core documents with when to read each, which ones apply to which readers, and a short note explaining that the numbering starts at 02 because this document is 01.

It is deliberately not a copy of the root START HERE. Root START HERE indexes the whole toolkit; this one orients you inside the Core folder.

**Status in Drive:** DONE.
**Status in markdown:** No change needed. [Core: start here](../01%20Core%20-%20applies%20to%20everyone/01-core-start-here.md) already existed and already served this role.

### Lesson

The root START HERE absorbed two markdown files, [Start here](00-start-here.md) and [Core: start here](../01%20Core%20-%20applies%20to%20everyone/01-core-start-here.md). Merging the README was right, because a Drive folder listing does what a README does. Merging the Core start-here was wrong, because it was a folder entry document, not a repository readme. They looked like the same kind of file and were not.

## Change 4: you are the business, plus three corrections

**Date:** 14 September 2026
**Reason:** Re-reading the toolkit as a sole-director, sole-employee Pty Ltd exposed a missing subject and three factual errors.

### Added

[You are the business](../01%20Core%20-%20applies%20to%20everyone/10-you-are-the-business.md) — no safety net if you cannot work, the escalation ladder for an unpaid invoice, and continuity if you are not there.

### Corrected

| Where | Was | Now |
|---|---|---|
| [Running a Pty Ltd](../01%20Core%20-%20applies%20to%20everyone/06-running-a-pty-ltd.md) | "If the company employs anyone else, COIDA registration applies" | Wrong. COIDA's definition of employee includes a working director under a contract of service. A director drawing a salary must register and submit a Return of Earnings even as the only person in the company. |
| [Register: what you actually need](../01%20Core%20-%20applies%20to%20everyone/02-register.md) | UIF and COIDA framed as a cost triggered by paying yourself | A sole proprietor is barred from both, so has no illness benefit and no injury cover at all. For a company it is a trade, not a catch. |
| [Glossary](../05%20Look%20it%20up/01-glossary.md) and [Vehicle dealer](../04%20Your%20kind%20of%20business/01-vehicle-dealer.md) | Small Claims Court cited without saying who may use it | Section 7(1) of the Small Claims Courts Act allows only natural persons to institute a claim. A company can be sued there but cannot sue. |

## Known structural differences between the two copies

These are deliberate, not errors.

| Markdown | Drive | Why |
|---|---|---|
| [Start here](00-start-here.md) | Merged into "00 START HERE" | A Drive folder listing does the job a README does, so a separate one was redundant. |
| [Core: start here](../01%20Core%20-%20applies%20to%20everyone/01-core-start-here.md) | Now exists in Drive as "01 Start here" in the Core folder | Was wrongly merged into START HERE when Drive was built, leaving the Core folder numbered 02 to 09. Corrected 14 September 2026. |
| [Which template to use when](../03%20Paperwork%20and%20templates/01-which-template-to-use-when.md) contains the templates as text | Split into a guide plus 5 fill-in Google Docs | Templates you copy and fill in are more useful than templates printed inside a guide. |
| Cash book and logbook are tables inside a markdown file | Two Google Sheets | A logbook you fill in on your phone beats one printed in a document. |
| Plain markdown blockquotes for "In plain words" | Grey shaded single-cell tables | Google Docs silently flattens blockquotes, so they would have been invisible. |
| Fenced code blocks for prompts | Grey shaded boxes in Courier | Makes the start and end of each prompt obvious for copying. |

## How to keep the two copies in sync

For a small change, edit the Google Doc directly. The document ID stays the same, so every link pointing at it keeps working.

For a full rewrite of one document, open the existing Google Doc, select all, delete, and paste the new content. The ID survives because the file does.

**Never download, edit and re-upload.** That creates a new file with a new ID, and every link in the toolkit would still point at the old one.

Update this changelog whenever you change either copy.
