# Dokumente en sjablone

Jy het ses dokumente nodig om 'n klein besigheid behoorlik te bestuur.

## Sjabloon 1: kwotasie

```
[JOU BESIGHEIDSNAAM]
[Foon] | [E-pos]

-------------------------------------------------------------
Beskrywing Hoeveelheid Eenheidsprys Bedrag
-------------------------------------------------------------
[Item of diens] 1 R 0.00 R 0.00
-------------------------------------------------------------
```

## Opdragte om die res te skep

```
Ek is 'n [BESIGHEIDSTIPE] in Suid-Afrika. Ek verkoop [WAT] aan [WIE].
Skryf bepalings en voorwaardes in eenvoudige Afrikaans.
```

Vir 'n maatskappy, wys albei name:

```
MOKOENA MOTORS
A trading name of Mokoena Holdings (Pty) Ltd | Reg. No. 2026/123456/07
```

Die kwotasiesjabloon is in `03-documents/02`.
