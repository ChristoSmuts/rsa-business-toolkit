# Documents and templates

You need six documents to run a small business properly.

## Template 1: quotation

```
[YOUR BUSINESS NAME]
[Phone] | [Email]

-------------------------------------------------------------
Description Qty Unit price Amount
-------------------------------------------------------------
[Item or service] 1 R 0.00 R 0.00
-------------------------------------------------------------
```

## Prompts to generate the rest

```
I am a [BUSINESS TYPE] in South Africa. I sell [WHAT] to [WHO].
Write terms and conditions in simple English.
```

For a company, show both names:

```
MOKOENA MOTORS
A trading name of Mokoena Holdings (Pty) Ltd | Reg. No. 2026/123456/07
```

The quote template is in `03-documents/02`.
